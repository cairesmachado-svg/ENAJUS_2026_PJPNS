# Política Judiciária como Campo Emergente · ENAJUS

Apresentação em HTML do artigo *Política Judiciária como Campo Emergente: da cartografia bibliométrica à maturidade observável das PJNP* (Machado, Bonani, Melo Filho e Cronemberger · CNJ/ENAJU).

Arquivo único, sem dependências além das fontes do Google Fonts. Abre offline com fontes de sistema.

## Publicar no GitHub Pages

1. Crie um repositório, por exemplo `enajus-pjnp`.
2. Envie `index.html`, `.nojekyll` e este `README.md` para a raiz da branch `main`.
3. Em **Settings › Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. O endereço será `https://<seu-usuario>.github.io/enajus-pjnp/`.

Pela linha de comando:

```bash
git init && git add . && git commit -m "Apresentação ENAJUS"
git branch -M main
git remote add origin https://github.com/<seu-usuario>/enajus-pjnp.git
git push -u origin main
```

## Comandos durante a apresentação

| Tecla | Ação |
|---|---|
| → · Espaço · Enter | Próximo slide |
| ← · Backspace | Slide anterior |
| N | Notas do apresentador com tempo-alvo e acumulado |
| T | Liga e desliga o cronômetro (meta de 20:00) |
| F | Tela cheia |
| Home · End | Primeiro e último slide |

Toque e deslize funcionam em tablet. Cada slide tem endereço próprio (`#5`, `#10`).

## Estrutura

14 slides principais (20 minutos) e 2 de apêndice para perguntas.
Código de cores: laranja para limites, verde para hipóteses (H1 a H5), roxo para eixos da agenda (A1 a A6).

## PDF de segurança

Abra no Chrome, use **Imprimir › Salvar como PDF**, margens **Nenhuma**, com gráficos de fundo ativados. Cada slide vira uma página 16:9.
